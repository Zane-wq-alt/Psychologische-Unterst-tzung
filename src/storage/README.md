# Storage layer

Локальное хранилище реализовано в `src/core/storage.js` и подключено к legacy runtime до инициализации состояния.

- Ключ совместимости: `localStorage["opora_v2"]`; текущая версия схемы: `schemaVersion: 1`.
- Модуль отвечает за чтение, миграцию, проверку структуры, запись, JSON import/export, backup list и restore.
- Резервные копии имеют формат `opora-local-backup` и хранят исходную строку без переформатирования.
- Облачный контракт изолирован в `cloud-sync.js`, по умолчанию выключен и не выполняет запросов.

Проверки: `node --test tests/*.test.cjs`; GitHub Actions дополнительно выполняет `node --check` для всех JavaScript-файлов в `src/`.

## Оставшаяся работа

Текущая схема v1 записывается под совместимым ключом после резервного копирования и проверки чтением обратно. Отдельный целевой namespace, двухфазное переключение и пользовательский итог миграции ещё не реализованы. Их следует выполнять отдельно, оставляя исходный `opora_v2` нетронутым до успешной сверки.
