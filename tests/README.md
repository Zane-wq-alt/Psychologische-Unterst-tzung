# Tests

Запуск локально: `node --test tests/*.test.cjs` (Node.js 20+).

## Fixtures

- `fixtures/legacy-full.json` — полный legacy-объект с записями профиля, чек-инов, эпизодов, архива чата и неизвестными полями.
- `fixtures/legacy-partial.json` — частично заполненное состояние.
- `fixtures/malformed.txt` — повреждённый JSON.

## Автоматические сценарии

1. Миграция legacy-данных и резервирование исходной строки.
2. Сохранение неизвестных полей и архива.
3. Частичные данные и идемпотентный повторный запуск.
4. Повреждённый JSON без перезаписи.
5. Некорректные типы коллекций без потери исходной строки.
6. Отклонение некорректного импорта.
7. Резервная копия перед успешным импортом.
8. Отмена операции при невозможности создать backup.
9. Rollback исходной строки при ошибке записи.
10. Восстановление backup и сохранение текущей версии перед откатом.
11. Защита от неизвестной будущей версии схемы.

GitHub Actions workflow: `.github/workflows/opora-storage-tests.yml`.

Браузерные e2e-проверки, офлайн-обновление PWA и проверка на живом профиле в этот набор не входят.
