# Аудит исходной версии «Опоры»

Дата аудита: 2026-11-13
Исходная версия: main, базовый commit 31e10713d86e361b0e3215f380b38c958aac49fb.

## Состав и размер
- Почти всё приложение находилось в одном index.html размером около 666 KB.
- Было 3 script-блока: загрузчик шрифта, основной runtime и регистрация Service Worker.
- Основной JavaScript занимал около 649 KB; CSS — около 15.8 KB.
- В runtime найдено около 182 объявлений функций; в интерфейсе — 80 заголовков и 63 уникальных HTML id.
- README.md отсутствовал.

## Функциональность
Главная и чек-ин, графики и закономерности, подготовка к событиям и оценка ресурсов, рутины и напоминания, дыхание и заземление, звуки и игры, журнал эпизодов, запуск задач, эмоции, фразы и карточки общения, профиль, отчёты, экспорт и импорт JSON/CSV.

## Хранение
- Основной ключ localStorage: opora_v2.
- Данные включают профиль, чек-ины, эпизоды, события, заметки, настройки и историю чата.
- migrate() дополняет отсутствующие поля значениями по умолчанию.
- Исходный код ограничивал новые записи: чек-ины — 400, эпизоды — 300, чат — 30; также существовали ограничения размера отдельных частей.
- Экспорт/импорт JSON уже был; импорт заменял текущее состояние.
- В этой ветке сохраняются ключ и структура legacy-данных; новые сохранения больше не обрезают историю чата. Версионированная схема и проверяемый rollback остаются следующей задачей.

## Claude и облако в исходной версии
- Облачный адаптер использовал window.claude.use("user") и window.claude.use("db").
- Записи синхронизировались в data/users/{uid}/{part}.
- Через то же окружение подключались sample для генеративных ответов и downloads для файлов.
- ИИ-чат передавал модели профиль и сводки записей: чек-ины, эпизоды, события, заметки и другие сведения.
- Поэтому удаления одного экрана чата было недостаточно: Claude был связан также с синхронизацией и скачиванием.

## PWA
- Использовались manifest.webmanifest и sw.js.
- Исходный Service Worker кэшировал HTML, manifest и иконки; после выделения файлов CSS/JS их необходимо добавить в precache.
- В этой ветке cache version обновлена, а внешние CSS/JS включены в список precache.

## Изменения этой ветки
- Удалены Claude runtime bindings, ИИ-чат, промпт, сбор контекста и вызовы модели.
- Удалена связанная с Claude синхронизация. Приложение работает локально; независимое облако пока не включено.
- Старый S.chat остаётся в локальных данных и показывается как архив для просмотра.
- Скачивание файлов работает через браузерные Blob/URL API.
- CSS и JS вынесены в отдельные файлы; добавлены README, аудит и архитектурный каркас.
- main не меняется.

## Ограничения и проверки
- Нужна ручная проверка Android/desktop, импорта/экспорта, офлайна и обновления PWA.
- Реальное localStorage пользователя GitHub не видит: сохранность проверяется на копии профиля.
- Данные, существующие только в прежнем облаке, этой веткой не удаляются, но новая версия к ним больше не подключается. Если они есть, их нужно отдельно экспортировать из прежней среды.
- Следующая задача — версия схемы, безопасная миграция, резервная копия/откат и автоматические тесты.
