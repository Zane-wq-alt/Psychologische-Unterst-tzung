Дата проверки: 2026-11-14  
Рабочая ветка: `opora-v2-development`  
Ограничения: `main` не изменять; не выполнять merge или release без отдельного разрешения.

## Что изменено

- Runtime больше не загружает монолитный `src/legacy/app.js`; его содержимое разложено по файлам в `src/legacy/`, `src/core/`, `src/ui/` и `src/features/`.
- Порядок подключения модулей явно зафиксирован в `index.html`; новые файлы включены в precache Service Worker.
- Старая версия Service Worker заменяется cache version `opora-v14`.
- Удалён внешний загрузчик Google Fonts: приложение не делает запрос к fonts.googleapis.com ради шрифта.
- Обычное автосохранение теперь возвращает прежнюю строку localStorage при неудачной записи. Автосохранения не создают отдельную резервную копию на каждый ввод.
- Добавлены тесты для rollback обычного сохранения, локального privacy view и контракта синхронизации.

## Облачная синхронизация: границы текущей реализации

Облачная синхронизация по умолчанию выключена. Модуль `src/storage/cloud-sync.js` не содержит провайдера, SDK, адреса сервера или секретов. Он требует переданный транспорт и отдельное явное согласие; при несовпадении ревизий возвращает конфликт и не перезаписывает удалённую копию.

Рекомендация и сравнение Supabase, Firebase и Appwrite записаны в `docs/CLOUD_SYNC_BACKEND.md`. Для завершения реальной синхронизации необходимы создание отдельного backend владельцем, настройка Auth и RLS, проверка доступа двумя тестовыми пользователями, проверка удаления и конфигурация окружения. Эти ресурсы нельзя безопасно создать или угадать из публичного репозитория. До этого момента локальный режим остаётся единственным активным режимом.

## Проверки и ограничения

- Автоматические проверки запускаются GitHub Actions: синтаксис всех JavaScript-файлов и `node --test tests/*.test.cjs`.
- Проверка браузерного интерфейса, Android/iOS, реального PWA offline/upgrade цикла и восстановления на копии пользовательского профиля всё ещё требуется.
- Тестовые fixtures не являются пользовательскими данными. Реальный localStorage пользователя не читался и не изменялся.
- Экспорт JSON не зашифрован отдельным паролем.
- Исторические диалоги остаются локальным архивом; генеративный чат не запускается.

## Безопасность выпуска

Никаких изменений в `main`, merge или release не выполнялось. Не публиковать эту ветку как production до завершения перечисленных ручных проверок и настройки облака (если облако действительно требуется).
