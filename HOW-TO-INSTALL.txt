Установка «Опоры» на Android

Вариант А: Netlify
1. Откройте app.netlify.com/drop и войдите в аккаунт.
2. Загрузите папку проекта целиком, сохранив структуру файлов (index.html, src/, sw.js, manifest.webmanifest и иконки).
3. Откройте полученную ссылку в Chrome.
4. Меню ⋮ > «Установить приложение».

Вариант Б: GitHub Pages
1. Создайте репозиторий на github.com.
2. Загрузите ВСЕ файлы проекта с сохранением папок и структуры.
3. Settings > Pages > Deploy from a branch > main / root > Save.
4. Откройте опубликованную ссылку в Chrome и установите приложение.

Важно
- Основные данные хранятся локально на устройстве в браузере.
- Перед обновлением браузера, очисткой данных или переносом устройства скачайте копию: «Ещё» > «Отчёт и данные» > «Скачать копию (JSON)».
- Очистка данных браузера может удалить локальные записи.
- Версия 2.0 не использует Claude и не содержит ИИ-помощника. Облачная синхронизация временно отключена до разработки независимого сервиса; локальная работа и резервные копии не зависят от облака.
- Загружайте всю папку проекта, а не только index.html: приложение использует отдельные файлы CSS и JavaScript.
