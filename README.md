# Опора

«Опора» — локальное PWA-приложение для самонаблюдения, планирования и инструментов самоподдержки. Оно не ставит диагнозов и не заменяет профессиональную помощь.

## Запуск
Откройте сайт через HTTPS (например, GitHub Pages или Netlify) либо локальный статический сервер. Загружать нужно весь проект: index.html использует src/ui/legacy.css и src/legacy/app.js.

## Данные и приватность
- Данные хранятся локально в браузере (localStorage, ключ opora_v2).
- Регистрация не требуется.
- Claude и генеративный ИИ удалены.
- Облачная синхронизация пока отключена; локальная работа не зависит от сети.
- Делайте JSON-резервную копию через «Ещё» → «Отчёт и данные».

Работа ведётся в ветке opora-v2-development. main не изменялась. Runtime вынесен в переходный legacy-слой; постепенная декомпозиция и автоматические тесты продолжаются.
