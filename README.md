# Опора

«Опора» — локальное PWA-приложение для самонаблюдения, планирования и инструментов самоподдержки. Оно не ставит диагнозов и не заменяет профессиональную помощь.

## Запуск
Откройте сайт через HTTPS (например, GitHub Pages или Netlify) либо локальный статический сервер. Загружать нужно весь проект: index.html использует src/ui/legacy.css, src/core/storage.js и src/legacy/app.js.

## Данные и приватность
- Данные хранятся локально в браузере (localStorage, ключ opora_v2).
- Регистрация не требуется.
- Claude и генеративный ИИ удалены.
- Облачная синхронизация по умолчанию отключена; имеется отдельный opt-in контракт, но backend пока не настроен.
- Генеративный ИИ не входит в runtime; внешняя загрузка Google Fonts удалена.
- Делайте JSON-резервную копию через «Ещё» → «Отчёт и данные».
- Перед миграцией, импортом и сбросом приложение сохраняет исходный JSON в отдельную локальную точку восстановления.
- При повреждённом или неподдерживаемом хранилище запись блокируется; исходное содержимое можно скачать и восстановить после проверки.
- Резервные копии — обычный JSON без шифрования; храните скачанные файлы в безопасном месте.

## Статус
Работа ведётся в ветке opora-v2-development. main не изменялась. Runtime разделён на упорядоченные файлы; переход с глобальных classic scripts на ES modules, настройка реального облачного backend и ручные проверки PWA/устройств остаются следующими задачами.
